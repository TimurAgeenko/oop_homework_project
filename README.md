# Ядро для интернет-магазина

## Описание:

Этот репозиторий содержит ядро для создания интернет-магазина на Python.

## Установка:

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/TimurAgeenko/oop_homework_project
   ```
   
2. Установите необходимые зависимости:
   ```
   pip install
   ```
   
## Использование:

1. Класс "BaseProduct" является абстрактным классом, который определяет общие атрибуты и методы для всех товаров. Он не может быть инициирован напрямую.

2. Класс "BaseCategoryOrder" является абстрактным классом, который определяет общие атрибуты и методы для категорий и заказов. Он не может быть инициирован напрямую.
   
3. Класс "Product" представляет товар с атрибутами: название, описание, цена и количество на складе.
   ```
   Чтобы создать товар, используйте следующий код:
   product = Product("Название товара", "Описание товара", "Цена", "Количество на складе")
   ```
   
4. У класса "Product" есть класс-метод new_product, который используется для создания нового товара из словаря.
   ```
   product_data = {
       "name": "Название товара",
       "description": "Описание товара",
       "price": 100,
       "quantity": 10
   }
   product = Product.new_product(product_data)
   ```
   
5. У класса "Product" есть геттер и сеттер для атрибута "price"(цена товара).
   ```
   product = Product("Название товара", "Описание товара", 100, 10)
   print(product.price)  # Получение цены товара
   product.price = 150   # Установка новой цены товара
   print(product.price)  # Выводит: 150
   ```
   
6. У класса "Product" есть метод __str_, который возвращает строковое представление товара.
   ```
   product = Product("Название товара", "Описание товара", 100, 10)
   print(product)  # Выводит: '"Название товара", 100 руб. Остаток: 10 шт.'
   ```
   
7. У класса "Product" есть метод __add__, который позволяет складывать два товара,
   возвращая общую стоимость всех товаров, хранящихся на складе.
   ```
   product1 = Product("Товар 1", "Описание товара 1", 100, 10)
   product2 = Product("Товар 2", "Описание товара 2", 150, 5)
   total_price = product1 + product2
   print(total_price)  # Выводит: 2750
   ```
   
8. Класс "Category" представляет категорию товаров с атрибутами: название категории, описание и список товаров в категории.
   ```
   Чтобы создать категорию, используйте следующий код:
   category = Category("Название категории", "Описание категории", ["Список товаров"])
   ```
   
9. У класса "Category" есть метод add_product, который добавляет товар в категорию.
   ```
   category = Category("Электроника", "Категория электроники", [])
   product = Product("Название товара", "Описание товара", 100, 10)
   category.add_product(product)
   ```
   
10. У класса "Category" есть геттер для атрибута "products"(список товаров в категории).
   ```
   category = Category("Электроника", "Категория электроники", [])
   product = Product("Название товара", "Описание товара", 100, 10)
   category.add_product(product)
   print(category.products)  # Выведет '"Название товара", 100 руб. Остаток: 10 шт.'
   ```
   
11. У класса "Category" есть метод __str__, который возвращает строковое представление категории и ее товаров.
   ```
   category = Category("Электроника", "Категория электроники", [])
   product = Product("Название товара", "Описание товара", 100, 10)
   category.add_product(product)
   print(category)  # Выводит: "Электроника, Количество: 10 шт."
   ```
   
12. У класса "Category" есть метод products_list, который возвращает список всех товаров в категории.
    ```
    category = Category("Электроника", "Категория электроники", [])
    product1 = Product("Товар 1", "Описание товара 1", 100, 10)
    product2 = Product("Товар 2", "Описание товара 2", 150, 5)
    category.add_product(product1)
    category.add_product(product2)
    print(category.products_list[0].name)  # Выводит: "Товар 1"
    ```

13. Функция get_classes_from_data используется для создания классов из JSON-файла. Принимает путь к JSON-файлу в качестве аргумента
   и возвращает список объектов класса "Category". Если путь не передан, по умолчанию используется путь "../data/products.json"
   ```
   categories = get_classes_from_data()
   print(categories[0].products[0].name)
   
   Выдаст:
   Samsung Galaxy C23 Ultra
   ```

14. Класс CategoryIterator представляет итератор для обхода товаров в категории.
    Он реализует методы __iter__ и __next__ для итерации по товарам.
    ```
    category = Category("Электроника", "Категория электроники", [])
    product1 = Product("Товар 1", "Описание товара 1", 100, 10)
    product2 = Product("Товар 2", "Описание товара 2", 150, 5)
    category.add_product(product1)
    category.add_product(product2)

    iterator = CategoryIterator(category)
    for product in iterator:
        print(product.name)  # Выводит: "Товар 1" и "Товар 2"
    ```
    
15. Класс Smartphone представляет смартфон, он наследуется от класса "Product" и добавляет следующие атрибуты:
    efficiency, model, memory, color.
    ```
    Чтобы создать смартфон, используйте следующий код:
    smartphone = Smartphone(
        "Название смартфона",
        "Описание смартфона",
        "Цена",
        "Количество на складе",
        "Эффективность",
        "Модель",
        "Объём памяти",
        "Цвет"
    )
    ```
    
16. Класс LawnGrass представляет газонную траву, он наследуется от класса "Product" и добавляет следующие атрибуты:
    country, germination_period, color.
    ```
    Чтобы создать газонную траву, используйте следующий код:
    lawn_grass = LawnGrass(
        "Название",
        "Описание",
        "Цена",
        "Количество на складе",
        "Страна-производитель",
        "Период прорастания",
        "Цвет"
    )
    ```
    
17. Класс MixinLogger представляет миксин для вывода информации о товаре в консоль при инициализации объекта класса "Product" или его наследников.
    ```
    product = Product("Название товара", "Описание товара", "Цена", "Количество на складе")
    
    Выводит в консоль:
    Product('Название товара', 'Описание товара', "Цена", "Количество на складе")
    ```
    
18. Класс Order представляет заказ, он наследуется от класса "BaseCategoryOrder" и имеет следующие атрибуты:
    product, quantity.
    ```
    Чтобы создать заказ, используйте следующий код:
    product = Product("Название товара", "Описание товара", "Цена", "Количество на складе")
    order = Order(product, "Количество товара в заказе")
    ```
    
19. У класса "Order" есть геттер для атрибута "total_price"(общая стоимость заказа), который возвращает общую стоимость заказа, умножая цену товара на количество.
    ```
    product = Product("Название товара", "Описание товара", 100, 10)
    order = Order(product, 2)
    print(order.total_price)  # Выводит: 200
    ```
    
20. У класса "Order" есть метод __str__, который возвращает строковое представление заказа.
    ```
    product = Product("Название товара", "Описание товара", 100, 10)
    order = Order(product, 2)
    print(order)  # Выводит: "Заказ: "Название товара", Количество: 2 шт., Общая стоимость: 200 руб."
    ```
   
## Тестирование

Для запуска тестов выполните следующие шаги:

1. Убедитесь, что у вас установлен `pytest`
2. В терминале наберите `pytest`, чтобы запустить тестирование
3. Проверьте результаты в консоли

При тестировании используются юнит-тесты, их результаты выводятся в консоль.

Подробные отчеты о тестировании можно найти в директории `/htmlcov/`
