# Ядро для интернет-магазина

## Описание:

Этот репозиторий содержит ядро для создания интернет-магазина на Python.

## Установка:

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/TimurAgeenko/oop_homework_project
   ```
   
2. Установите необходимые зависимости:
   ```
   pip install
   ```
   
## Использование:

1. Класс "Product" представляет товар с атрибутами: название, описание, цена и количество на складе.
   ```
   Чтобы создать товар, используйте следующий код:
   product = Product("Название товара", "Описание товара", "Цена", "Количество на складе")
   ```
   
2. Класс "Category" представляет категорию товаров с атрибутами: название категории, описание и список товаров в категории.
   ```
   Чтобы создать категорию, используйте следующий код:
   category = Category("Название категории", "Описание категории", ["Список товаров"])
   ```
   
3. Функция get_classes_from_data используется для создания классов из JSON-файла. Принимает путь к JSON-файлу в качестве аргумента
   и возвращает список объектов класса "Category". Если путь не передан, по умолчанию используется путь "../data/products.json"
   ```
   categories = get_classes_from_data()
   print(categories[0].products[0].name)
   
   Выдаст:
   Samsung Galaxy C23 Ultra
   ```
   
## Тестирование

Для запуска тестов выполните следующие шаги:

1. Убедитесь, что у вас установлен `pytest`
2. В терминале наберите `pytest`, чтобы запустить тестирование
3. Проверьте результаты в консоли

При тестировании используются юнит-тесты, их результаты выводятся в консоль.

Подробные отчеты о тестировании можно найти в директории `/htmlcov/`
